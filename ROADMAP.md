# Roadmap

## v0.1

The atlas provides a sourced institutional network, evidence inspection, filters, comparisons and browser-local intake and review. The data model reserves project and transaction tables for later coverage. GitHub Pages can serve the static build.

## Next releases

1. Widen coverage of domestic pension reserves, balance-sheet insurers, local infrastructure equity managers and underserved country markets. Add source-level field provenance and track changes in corporate ownership over time.
2. Add a research workflow backend with reviewer identity, timestamped decisions and review history. Introduce claim-level evidence, proposed merges and conflicting-source resolution. Publish approved dataset changes through a controlled export.
3. Migrate the repository interface to PostgreSQL if the expanded registry needs shared editing or efficient queries. Model entity subtypes, evidence joins, transaction observation stages and related funds explicitly.
4. Connect projects and transaction observations where official disclosures support reconciled dates, amounts and intermediary roles. Add period and provenance controls before exposing regional analytics.
